# F1 · One record, one decision

**Applies to:** author.

**What holds.** Every decision lives in its own file with its own sequential number; there is no collection file holding all decisions.

**Why.** Only a separate file can apply as a whole or be superseded as a whole. In a collection file, status is an attribute of paragraphs, and paragraphs carry no status that a tool or a reader picks up reliably. It is also the only way to answer when a decision was made: the file carries its own date.

**Considered and rejected.** *One collection file with a section per decision*: convenient to search and tidy at first, but it forces amendment: a revision becomes a correction inside a paragraph, which is precisely what this concept sets out to prevent. *One record per topic area* ("everything about storage"): the boundaries shift over time, and every revision then touches neighboring decisions nobody meant to reopen.

**How you notice it is violated.** Someone asks "does the second paragraph still apply?", and nobody can answer it from the record.
