# immutable-decision-records

**These (de):** Ein angenommenes Entscheidungsdokument wird nie mehr geändert — jede
Änderung ist ein neues, vollständiges Dokument, das das alte ersetzt.

**Thesis (en):** An accepted decision record is never changed again — every change is a
new, complete record that replaces the old one.
