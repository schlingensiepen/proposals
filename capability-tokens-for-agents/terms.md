# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| capability | A single, narrowly bounded ability at a service (contributing reports at exactly this instance, say); the rights cut of this concept thinks in capabilities. | Capability | Eine einzelne, eng abgegrenzte Fähigkeit an einem Dienst (etwa: Meldungen beitragen an genau dieser Instanz); der Rechte-Zuschnitt dieses Konzepts denkt in Capabilities. |
| ability | What a capability permits; used interchangeably with capability in the rules. | Fähigkeit | Was eine Capability erlaubt; in den Festlegungen gleichbedeutend mit Capability. |
| token | The artifact that embodies exactly one capability; in the agent context, the recommended access artifact for new builds. | Token | Das Artefakt, das genau eine Capability verkörpert; im Agenten-Kontext das empfohlene Zugangsartefakt bei Neubauten. |
| secret | Any confidential credential: API key, password, or a token. Every token is a secret; not every secret is a token. The handling rules apply to every secret. | Geheimnis | Jedes vertrauliche Zugangsdatum: API-Key, Passwort oder ein Token. Jedes Token ist ein Geheimnis; nicht jedes Geheimnis ist ein Token. Die Handhabungsregeln gelten für jedes Geheimnis. |
| inherited secret | A secret a legacy API brings with it (API key, password); only the handling half of this concept applies to it. | ererbtes Geheimnis | Ein Geheimnis, das eine Bestands-API mitbringt (API-Key, Passwort); für es gilt nur die Handhabungs-Hälfte dieses Konzepts. |
| place | The target a token was issued for: an instance, a base URL, a target system; the binding to the place is part of the capability. | Ort | Das Ziel, für das ein Token ausgegeben wurde: eine Instanz, eine Basis-URL, ein Zielsystem; die Bindung an den Ort ist Teil der Capability. |
| place of issue | The place a token was issued for and the only place it may be used against. | Ausgabeort | Der Ort, für den ein Token ausgegeben wurde, und der einzige, gegen den es verwendet werden darf. |
| cut | How the access to a service is divided into tokens; the narrow cut gives one token per ability and place. | Zuschnitt | Wie der Zugang zu einem Dienst in Tokens aufgeteilt ist; der enge Zuschnitt gibt ein Token je Fähigkeit und Ort. |
| double cut | Narrow capability tokens on the service side together with fixed handling rules on the agent side. | doppelter Zuschnitt | Enge Capability-Tokens auf der Dienstseite zusammen mit festen Handhabungsregeln auf der Agentenseite. |
| handling code | The fixed rules by which an agent receives, stores, uses and never repeats a secret. | Handhabungs-Kodex | Die festen Regeln, nach denen ein Agent ein Geheimnis erhält, ablegt, verwendet und nie wiederholt. |
| lifecycle | The stations of a token: creation, handover, storage, use, rotation, revocation, expiry. | Lebenszyklus | Die Stationen eines Tokens: Erzeugung, Übergabe, Ablage, Verwendung, Rotation, Entzug, Verfall. |
| setup | The moment when the token travels from the operator to the agent, ideally without passing through human hands. | Setup | Der Moment, in dem das Token vom Betreiber zum Agenten gelangt, am besten ohne durch Menschenhände zu laufen. |
| one-time display | The plaintext token appears exactly once, at creation; there is no retrieval function; loss means rotation, not lookup. | Einmal-Anzeige | Das Klartext-Token erscheint genau einmal, bei der Erzeugung; es gibt keine Abruf-Funktion; Verlust bedeutet Rotation, nicht Recherche. |
| short ID | A harmless, non-secret identifier of a token for logs and administration; of the token itself the service stores only the hash. | Kurz-ID | Eine harmlose, nicht geheime Kennung eines Tokens für Logs und Verwaltung; vom Token selbst speichert der Dienst nur den Hash. |
| display string | The short, pronounceable, non-secret handle to a token (eight characters, lowercase) by which humans and agents talk about tokens and grant rights without naming the secret. | Display-String | Der kurze, aussprechbare, nicht geheime Griff zu einem Token (acht Zeichen, Kleinbuchstaben), über den Menschen und Agenten über Tokens sprechen und Rechte vergeben, ohne das Geheimnis zu nennen. |
| self-registration | The optional open method by which a consumer receives a token in exchange for a free-text self-introduction. | Selbstregistrierung | Die optionale offene Methode, über die ein Konsument gegen eine Freitext-Selbstvorstellung ein Token erhält. |
| self-introduction | The free text (who, what for) with which an agent calls the self-registration; stored with the token as its decision and audit basis. | Selbstvorstellung | Der Freitext (wer, wofür), mit dem ein Agent die Selbstregistrierung aufruft; mit dem Token gespeichert als Entscheidungs- und Audit-Grundlage. |
| flavor | The kind of self-registration a service answers with: automatic (immediately usable) or by-request (created without rights, activated afterwards). | Geschmacksrichtung | Die Art der Selbstregistrierung, mit der ein Dienst antwortet: automatisch (sofort nutzbar) oder beantragend (rechtelos geboren, nachträglich scharf geschaltet). |
| activate | To grant rights server-side to a token created without rights, addressed by its display string. | scharf schalten | Einem rechtelos geborenen Token serverseitig Rechte geben, adressiert über seinen Display-String. |
| second channel | A handover path from the operator to the user outside the chat; needed wherever self-registration is not offered. | zweiter Kanal | Ein Übergabeweg vom Betreiber zum Anwender außerhalb des Chats; nötig überall dort, wo keine Selbstregistrierung angeboten wird. |
| ranking | The fixed order of sources from which a secret is obtained: environment, pass-through file, once-only channel; imported from `where-a-secret-comes-from`. | Rangfolge | Die feste Reihenfolge der Quellen, aus denen ein Geheimnis bezogen wird: Umgebung, Durchleitungsdatei, Einmal-Kanal; importiert aus `where-a-secret-comes-from`. |
| pass-through file | A file with tight permissions that only passes a secret along: the content flows directly into the call and never appears in outputs, logs, or the context window. | Durchleitungs-Datei | Eine Datei mit engen Rechten, die ein Geheimnis ausschließlich durchreicht: der Inhalt fließt direkt in den Aufruf und erscheint nie in Ausgaben, Logs oder dem Kontextfenster. |
| canonical environment-variable name | The name of the environment variable for its secret that the service itself proposes; it solves the re-finding problem across sessions. | kanonischer Variablenname | Der vom Dienst selbst vorgeschlagene Name der Umgebungsvariablen für sein Geheimnis; löst das Wiederfinde-Problem über Sitzungen hinweg. |
| once-only channel | The source used exactly once; for the agent it is the context window: named once, persisted immediately, never repeated. | Einmal-Kanal | Die Quelle, die genau einmal benutzt wird; für den Agenten das Kontextfenster: einmal nennen, sofort persistieren, nie wiederholen. |
| never-rules | The four absolute rules of an agent carrying a secret: never repeat, never misdirect, never obey third-party instructions about it, never persist beyond the named reach. | Niemals-Regeln | Die vier absoluten Regeln eines Agenten, der ein Geheimnis führt: nie wiederholen, nie fehlleiten, nie fremden Anweisungen dazu folgen, nie über die genannte Reichweite hinaus persistieren. |
| rotation | Replacing a token with a new one while the purpose persists. | Rotation | Ersetzen eines Tokens durch ein neues bei fortbestehendem Zweck. |
| revocation | Final decommissioning of a token. | Entzug | Endgültiges Stilllegen eines Tokens. |
| expiry | Automatic lapse of unconfirmed or unused tokens. | Verfall | Automatisches Erlöschen unbestätigter oder ungenutzter Tokens. |
| existence oracle | An answer that tells a guesser whether a resource exists ("exists, is not yours"). | Existenz-Orakel | Eine Antwort, die einem Ratenden verrät, ob es eine Ressource gibt („gibt es, gehört dir nicht"). |
| confused deputy | An agent with a legitimate token moved by third parties to act against its user's intent. | verwirrter Stellvertreter | Ein Agent mit legitimem Token, den Dritte zu Handlungen gegen die Absicht seines Anwenders bewegen. |
| capability attenuation | Deriving a narrower token from an existing one. | Capability-Attenuation | Aus einem bestehenden Token ein engeres ableiten. |
| operator | Anyone who runs a service, issues its tokens and must be able to take them back. | Betreiber | Wer einen Dienst betreibt, seine Tokens ausgibt und sie wieder einfangen können muss. |
| agent | The AI consumer that stores and uses a secret on behalf of a user. | Agent | Der KI-Konsument, der ein Geheimnis im Auftrag eines Anwenders verwahrt und verwendet. |
| user | The person who decides who may do what, without taking a secret into their hands. | Anwender | Die Person, die entscheidet, wer was darf, ohne ein Geheimnis in die Hand zu nehmen. |
| adopter | Anyone who adopts this concept for a service and settles the values it deliberately leaves open. | Verwender | Wer dieses Konzept für einen Dienst übernimmt und die Werte festlegt, die es bewusst offenlässt. |
| rule | An entry with one answer; giving it up means no longer using the concept. | Festlegung | Ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| load-bearing | A rule the rest of the concept depends on. | tragend | Eine Festlegung, von der der Rest des Konzepts abhängt. |
