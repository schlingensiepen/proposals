# capability-tokens-for-agents

**These (de):** Ein Token verkörpert genau eine Fähigkeit an genau einem Ort, und seine Handhabung folgt festen Regeln entlang des Lebenszyklus — denn im Agenten-Kontext ist jedes Leck durchsuchbar und kopierbar; wer Zuschnitt und Handhabung beide festlegt, übersteht Teilversagen glimpflich.

**Thesis (en):** A token embodies exactly one capability at exactly one place, and its handling follows fixed rules along the lifecycle — because in the agent context every leak is searchable and copyable; whoever pins down both the cut and the handling survives partial failure gracefully.
