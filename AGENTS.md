# Agent Entry Point

This repository is a series of self-contained dossiers ("proposals") that present proven
concepts — each readable as a discussion paper (German original leading, English
translation) and usable, unchanged, as a work instruction for AI agents.

You are here for one of two jobs. Read only the file for yours:

| Your job | Read |
|---|---|
| **Create or maintain** a dossier (Konzept or Kompendium): new dossier, revision, translation sync, status change | [agents/create-or-maintain.md](agents/create-or-maintain.md) |
| **Find and use** knowledge: locate the right dossier, decide whether to load it, apply it | [agents/find-and-use.md](agents/find-and-use.md) |

Iron rules that apply to both jobs:

- Every dossier must stay understandable and followable with every link dead
  (self-containment).
- German (`PROPOSAL.de.md`) is the leading version; F and Q numbers are stable across
  languages.
- Nothing is reinterpreted retroactively; version and status change only via the
  dossier's `CHANGELOG.md`.
- Attribution is "the author" / „der Autor" — never personal names.
