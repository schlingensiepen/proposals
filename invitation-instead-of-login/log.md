## 2026-08-15
* **Creation**: Version 1.0, first complete version (status: draft). Ten rules: no guests (F1), invitation instead of registration (F2), the invitation token is not the credential and every device knows its origin (F3), one credential per device, "user on device" (F4), authorization against the store, not the credential (F5), identity for humans and capability for machines (F6), machine accesses only in the bootstrap window (F7), the bootstrap as a time window instead of a delete-me file (F8), secrets in addresses only in the fragment (F9), two anchors for a rights system with five requirements on it (F10). One link, all devices, as an advantage rather than a concession; the credential in a server-set cookie, with the 400-day cap and the alias trap; "device" means browser profile; three levers against a forwarded link; creating is time-limited, revoking always available. No reference implementation yet.
