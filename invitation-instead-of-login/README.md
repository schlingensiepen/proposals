# invitation-instead-of-login

**These (de):** Zugang entsteht durch Einladung — ein Link lädt einen Benutzer für alle
seine Geräte ein, weil jedes Einlösen einen eigenen Nachweis erzeugt; Maschinen bekommen
Fähigkeit statt Identität.

**Thesis (en):** Access arises from an invitation — one link invites a user for all their
devices, because every redemption creates its own credential; machines receive capability
rather than identity.
