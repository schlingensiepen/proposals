# Sources

## Imports

This proposal imports no other proposal.

## Related

* `immutable-decision-records` (overlaps-with): the same figure of thought on another subject, a document that is never changed again but replaced; deepening, not a prerequisite. This concept differs in that attachments are carried over by reference instead of replaced with everything else; the difference has a reason (F2) and is still to be named.

All proposals live in the same repository; see its root README for the register and the links. Which proposals build on this one is listed in [`used-by.md`](./used-by.md).
