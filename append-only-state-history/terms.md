# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Item | the identity to which the history belongs; carries no data of substance itself. | Gegenstand | die Identität, an der die Geschichte hängt. Trägt selbst keine inhaltlichen Daten. |
| State | a complete snapshot with a point in time and a creator; immutable as soon as a further state follows it. | Zustand | eine vollständige Momentaufnahme mit Zeitpunkt und Urheber. Unveränderlich, sobald ein weiterer Zustand darauf folgt. |
| Attachment | a file that belongs to a state and can occur in several states without existing several times. | Anhang | eine Datei, die zu einem Zustand gehört und in mehreren Zuständen vorkommen kann, ohne mehrfach zu existieren. |
| Carry-over by reference | a new state inherits attachments of the previous one by pointing to them. | Übernahme per Verweis | ein neuer Zustand erbt Anhänge des vorigen, indem er auf sie zeigt. |
| Living metadata entry | the one exception: a piece of information on the latest state that may still be added to. | Lebendes Metadatum | die eine Ausnahme: eine Angabe am letzten Zustand, die noch ergänzt werden darf. |
| Builder | the role the rules apply to (`applies_to`): anyone who builds the system that keeps the states. | Erbauer | die Rolle, für die die Festlegungen gelten (`applies_to`): wer das System baut, das die Zustände führt. |
| Rule | an entry with one answer; giving it up means no longer using the concept. | Festlegung | ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
