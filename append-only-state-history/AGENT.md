# Agent guide

## Purpose

You are keeping the history of an item so that it cannot be changed afterwards, without every change duplicating everything. This concept is a fragment: **for flat items** (one item, a sequence of states, attachments on them) **it is applicable. For items that are themselves trees, it is not an answer** but an open question with some groundwork; the scope says what is open. If the item is a tree, put that question to the user; do not decide it yourself.
