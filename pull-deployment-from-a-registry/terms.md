# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Image | the built container image: the one deliverable that is published, pulled and started. | Abbild | das gebaute Container-Image: das eine Erzeugnis, das veröffentlicht, gezogen und gestartet wird. |
| Registry | a service that holds images under names and delivers them on request. Meant is the thing, not a product: the registry of a source host, a registry service of your own or a third-party offer are interchangeable for this concept. | Registry | ein Dienst, der Abbilder unter Namen bereithält und auf Anfrage ausliefert. Gemeint ist die Sache, nicht ein Produkt: die Registry eines Quelltext-Hosters, ein eigener Registry-Dienst oder ein Angebot Dritter sind für dieses Konzept austauschbar. |
| Build service | the environment in which the build pipeline runs: on every change to the source it builds, checks and publishes; likewise interchangeable. | Bauzuliefer-Dienst | die Umgebung, in der die Bauleitung läuft: bei jeder Änderung an der Quelle baut, prüft und veröffentlicht sie; ebenfalls austauschbar. |
| Build pipeline | the versioned description of what the build service does: build, smoke test, compute names, publish. | Bauleitung | die versionierte Beschreibung dessen, was der Bauzuliefer-Dienst tut: bauen, Rauchtest, Namen berechnen, veröffentlichen. |
| Smoke test | the run of the built image in the build environment, before publishing, with a fixed list of assertions (F2). | Rauchtest | der Lauf des gebauten Abbilds in der Bauumgebung, vor der Veröffentlichung, mit einer festen Liste von Zusicherungen (F2). |
| Health check | the check the image itself carries and the container runtime evaluates; the image's promise about itself. | Gesundheitsprüfung | die Prüfung, die das Abbild selbst mitbringt und die Container-Laufzeit auswertet; die Zusage des Abbilds über sich selbst. |
| State location | the place outside the container where the service keeps its state; it must survive removing and recreating the container. | Zustandsort | der Ort außerhalb des Containers, an dem der Dienst seinen Zustand hält; er muss das Entfernen und Neuanlegen des Containers überleben. |
| Throwaway value | a value used only in the smoke test, worthless afterwards, because the build log may be public. | Wegwerf-Wert | ein Wert, der nur im Rauchtest benutzt wird und danach wertlos ist, weil das Bauprotokoll öffentlich sein kann. |
| Red run | running an assertion once with its safeguard removed to see that it fails; an assertion that never turns red checks nothing. | Rot-Probe | eine Zusicherung einmal mit entfernter Absicherung laufen lassen und sehen, dass sie scheitert; eine Zusicherung, die nie rot wird, prüft nichts. |
| Name (tag) | the readable pointer under which an image is found in the registry. A pointer, not content. | Name (Tag) | der lesbare Zeiger, unter dem ein Abbild in der Registry gefunden wird. Ein Zeiger, kein Inhalt. |
| Moving name | a name that can point to a different image after every build (a branch, a version, `latest`). | beweglicher Name | ein Name, der nach jedem Bau auf ein anderes Abbild zeigen kann (ein Zweig, eine Fassung, `latest`). |
| Immutable name | a name that denotes exactly one build (a name derived from the source revision). | unveränderlicher Name | ein Name, der genau einen Bau bezeichnet (ein Name aus dem Quellstand). |
| Digest | the content-based identifier of an image, computed from its content; immutable, but known only after the build and not readable. | Digest | die inhaltsbezogene Kennung eines Abbilds, aus seinem Inhalt berechnet; unveränderlich, aber erst nach dem Bau bekannt und nicht lesbar. |
| Manifest | the description of an image in the registry that a fetch under a name or digest returns; whoever gets the manifest may pull the image. | Manifest | die Beschreibung eines Abbilds in der Registry, die ein Abruf unter einem Namen oder Digest zurückgibt; wer das Manifest bekommt, darf das Abbild ziehen. |
| Build stamp | the source revision the image was built from, recorded in the image and reported by the running service; a precondition here, not the subject. | Baustempel | der Quellstand, aus dem das Abbild gebaut wurde, in das Abbild eingetragen und vom laufenden Dienst genannt; hier Voraussetzung, nicht Gegenstand. |
| Default branch | the branch of version control that counts as the recommended state; this concept assumes there is exactly one. | Standardzweig | der Zweig der Versionsverwaltung, der als der empfohlene Stand gilt; dieses Konzept nimmt an, dass es genau einen gibt. |
| Deployment file | the file with which the operator starts the image (in the common pattern a Compose file); it belongs to the deliverable and is versioned with the source. | Ausrolldatei | die Datei, mit der der Betreiber das Abbild startet (im verbreiteten Muster eine Compose-Datei); sie gehört zum Erzeugnis und wird mit der Quelle versioniert. |
| Local cache of the container runtime | the images a machine holds locally; a known name is served from there and not pulled again. | Zwischenspeicher der Container-Laufzeit | die lokal vorgehaltenen Abbilder einer Maschine; ein bekannter Name wird von dort bedient und nicht neu gezogen. |
| Visibility | whether an image can be fetched without a login. A property of the image in the registry, separate from the visibility of the source repository and from a possible organization rule on whether public images are allowed at all. | Sichtbarkeit | ob ein Abbild ohne Anmeldung abrufbar ist. Eine Eigenschaft des Abbilds in der Registry, getrennt von der Sichtbarkeit des Quelltext-Repositoriums und von einer möglichen Regel der Organisation, ob öffentliche Abbilder überhaupt erlaubt sind. |
| Anonymous fetch | a fetch of the manifest without any login, from a machine that holds no stored credentials for the registry. | anonymer Abruf | ein Abruf des Manifests ohne jede Anmeldung, von einer Maschine, die keine gespeicherten Zugangsdaten für die Registry hat. |
| Outer edge | everything between the network and the service: the reverse proxy in front, the published ports, the advertisements to clients. | Außenkante | alles, was zwischen dem Netz und dem Dienst steht: der vorgelagerte Proxy, die veröffentlichten Ports, die Ankündigungen an Clients. |
| Protocol advertisement | an announcement by the outer edge to clients that a further route to the service exists (another protocol, another port); the common mechanism is the `Alt-Svc` header. | Protokollzusage | eine Ankündigung der Außenkante an Clients, dass ein weiterer Weg zum Dienst besteht (ein anderes Protokoll, ein anderer Port); der verbreitete Mechanismus ist die Kopfzeile `Alt-Svc`. |
| Push and pull | in a push, a deployer with access to the target transfers the deliverable; in a pull, the target fetches the deliverable from a registry itself, and nobody has access to the target. | Push und Pull | beim Push überträgt ein Ausliefernder mit Zugang zum Ziel; beim Pull holt sich das Ziel das Erzeugnis selbst aus einer Registry, und niemand hat Zugang zum Ziel. |
| Builder | whoever owns the source and the build pipeline and publishes the image. | Erbauer | wer die Quelle und die Bauleitung besitzt und das Abbild veröffentlicht. |
| Operator | whoever pulls, starts and checks the image on their machine. | Betreiber | wer das Abbild auf seiner Maschine zieht, startet und prüft. |
| Pattern | the concrete forms in this bundle (name schemes, the smoke-test list, the header of a deployment file) are patterns, not a house convention: the words are the author's choice; what they must achieve is binding. | Muster | die konkreten Formen in diesem Bundle (Namensschemata, die Liste des Rauchtests, der Kopf einer Ausrolldatei) sind Muster, keine Hauskonvention: Die Worte sind die Wahl des Autors; verbindlich ist, was sie leisten müssen. |
| rule | an entry with one answer; giving it up means no longer using the concept. | Festlegung | ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| choice | an entry where the concept does not decide but names options with consequences; the adopter decides and records. | Wahlpunkt | eine Stelle, an der das Konzept nicht entscheidet, sondern Optionen mit Folgen nennt; der Übernehmende entscheidet und hält fest. |
