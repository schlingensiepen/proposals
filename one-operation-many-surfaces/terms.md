# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Surface | a way in which the service is reached: the command, a surface over HTTP, further ones. | Fläche | ein Weg, auf dem der Dienst erreicht wird: das Kommando, eine Fläche über HTTP, weitere. |
| Second surface | a surface the service has beside its command, for instance over HTTP. | zweite Fläche | eine Fläche, die der Dienst neben seinem Kommando hat, etwa über HTTP. |
| Command | the one-off invocation of the same artifact for the same actions, started locally, without a login of its own. | Kommando | der Einmal-Aufruf desselben Artefakts für dieselben Handlungen, lokal gestartet, ohne eigene Anmeldung. |
| Action | something the service is asked to do on its store or its target system, for instance: create an account, issue an access, withdraw it, check the store, clean up the queue. | Handlung | etwas, das der Dienst an seinem Bestand oder seinem Zielsystem tun soll, etwa: Konto anlegen, Zugang ausstellen, entziehen, Bestand prüfen, Warteschlange aufräumen. |
| Access | the artifact with which a caller uses the function of the service, as a rule a token; issuing and withdrawing it are actions. | Zugang | das Artefakt, mit dem ein Aufrufer die Funktion des Dienstes benutzt, in der Regel ein Token; ihn auszustellen und zu entziehen sind Handlungen. |
| Operation | an action as a callable function that knows no surface, neither HTTP nor process exit: it takes arguments, acts on the store or the target system, and returns a result or an error kind of its own. Every operation exists exactly once. | Vorgang | eine Handlung als aufrufbare Funktion, die keine Fläche kennt, weder HTTP noch Prozessende: Sie nimmt Argumente, wirkt auf den Bestand oder das Zielsystem und gibt ein Ergebnis oder eine eigene Fehlerart zurück. Jeder Vorgang existiert genau einmal. |
| Pass-through | a surface that only calls existing operations and implements nothing itself: it reads arguments, calls the operation, translates the result into its vocabulary. The author's implementation calls the same thing a "facade"; this bundle does not, because in this series that word is used for something else (a retrofitted description service for a third-party interface that does not touch its traffic), and one word should not name two things. | Durchreiche | eine Fläche, die ausschließlich bestehende Vorgänge aufruft und nichts selbst umsetzt: Sie liest Argumente, ruft den Vorgang, übersetzt das Ergebnis in ihr Vokabular. Die Umsetzung des Autors nennt dasselbe „Fassade"; dieses Bundle nicht, weil das Wort in dieser Reihe für etwas anderes vergeben ist (einen nachgerüsteten Beschreibungsdienst einer fremden Schnittstelle, der deren Datenverkehr nicht berührt) und ein Wort nicht zwei Dinge bezeichnen soll. |
| Opening | the place where a surface offers one operation: a command on the command line, a route on an HTTP surface; a pass-through has one opening per operation. | Öffnung | die Stelle, an der eine Fläche einen Vorgang anbietet: ein Kommando auf der Kommandozeile, eine Route auf einer HTTP-Fläche; eine Durchreiche hat eine Öffnung je Vorgang. |
| Handler | the code of a network surface that answers one route; on the command line its counterpart is the command. | Handler | der Code einer Netzfläche, der eine Route beantwortet; auf der Kommandozeile ist sein Gegenstück das Kommando. |
| Translation function | the one function per surface that maps the error kinds of the operations to status codes or exit codes; the only place where HTTP or exit-code knowledge lives. | Übersetzungsfunktion | die eine Funktion je Fläche, die die Fehlerarten der Vorgänge auf Statuscodes beziehungsweise Exit-Codes abbildet; der einzige Ort, an dem HTTP- oder Exit-Code-Wissen wohnt. |
| Presentation | what a pass-through may have of its own besides the translation: where a line breaks, what goes to which channel, what a human sees instead of a machine. | Darstellung | was eine Durchreiche neben der Übersetzung an Eigenem haben darf: wo eine Zeile bricht, was auf welchen Kanal geht, was ein Mensch statt einer Maschine sieht. |
| Response model | the structure of what an operation returns; both surfaces emit it with the same field names. | Antwortmodell | die Struktur dessen, was ein Vorgang zurückgibt; beide Flächen geben es mit denselben Feldnamen aus. |
| Operational parameters | the settings the service runs with; besides the operations, the only thing a pass-through may import from its own service. | Betriebsparameter | die Einstellungen, mit denen der Dienst läuft; neben den Vorgängen das Einzige, was eine Durchreiche aus dem eigenen Dienst importieren darf. |
| Store | the data the operations of the service read and write (in the author's implementation: the accounts and their accesses). | Bestand | die Daten, die die Vorgänge des Dienstes lesen und schreiben (in der Umsetzung des Autors: die Konten und ihre Zugänge). |
| Target system | the external system an operation talks to (in the author's implementation: the mail server). | Zielsystem | das fremde System, mit dem ein Vorgang spricht (in der Umsetzung des Autors: der Mailserver). |
| Storage | where the service keeps its files and its store on disk; in the evidence, a pass-through may not reach it directly. | Ablage | wo der Dienst seine Dateien und seinen Bestand auf der Platte hält; in der Bewährung darf eine Durchreiche sie nicht direkt erreichen. |
| User-facing surface | in the evidence: the network surface of the service's actual function, beside which the administration surface stands. | Nutzfläche | in der Bewährung: die Netzfläche der eigentlichen Funktion des Dienstes, neben der die Verwaltungsfläche steht. |
| Gate | in the evidence: the set of checks a surface's description must pass in the build before it is published. | Gate | in der Bewährung: die Reihe von Prüfungen, die die Beschreibung einer Fläche im Bau bestehen muss, bevor sie veröffentlicht wird. |
| Deliverer | in the evidence: the part of the author's service that delivers the filed messages to the target system. | Zusteller | in der Bewährung: der Teil des Dienstes des Autors, der die abgelegten Nachrichten an das Zielsystem zustellt. |
| Structural test | a test in the build that parses the source of the pass-throughs (imports, names used, file system access, calls) and fails where an operation is performed there instead of called. | Strukturprüfung | eine Prüfung im Bau, die den Quelltext der Durchreichen zerlegt (Importe, verwendete Namen, Dateisystemzugriffe, Aufrufe) und fehlschlägt, wo dort ein Vorgang ausgeführt statt aufgerufen wird. |
| Behavioral test | a test that uses the service and checks its result; it cannot tell two correct copies apart. | Verhaltensprobe | eine Prüfung, die den Dienst benutzt und sein Ergebnis prüft; sie kann zwei richtige Kopien nicht auseinanderhalten. |
| Whitelist | the list of imports a pass-through may have from its own service: the operations and the operational parameters. Its opposite, a blacklist of forbidden imports, is rejected. | Weißliste | die Liste der Importe, die eine Durchreiche aus dem eigenen Dienst haben darf: die Vorgänge und die Betriebsparameter. Ihr Gegenstück, eine Schwarzliste verbotener Importe, ist verworfen. |
| Named exception | an exception to the file system ban that the structural test names by function and file, never as a pattern. | namentliche Ausnahme | eine Ausnahme vom Dateisystemverbot, die die Strukturprüfung mit Funktion und Datei nennt, nie als Muster. |
| Red check | running an assertion once with its protection removed and seeing it fail before trusting it. | Rot-Probe | eine Zusicherung einmal mit entfernter Absicherung laufen lassen und sie rot sehen, bevor man ihr traut. |
| Builder | anyone who builds or reviews the service; the role the rules of this bundle apply to. | Erbauer | wer den Dienst baut oder prüft; die Rolle, für die die Festlegungen dieses Bundles gelten. |
| Operator | anyone who runs the service; named in the costs and the evidence, not addressed by a rule. | Betreiber | wer den Dienst betreibt; in Kosten und Bewährung genannt, von keiner Festlegung angesprochen. |
| Rule | one answer of the concept; anyone who gives it up no longer uses the concept. | Festlegung | eine Antwort des Konzepts; wer sie aufgibt, benutzt das Konzept nicht mehr. |
