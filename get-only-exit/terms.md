# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| main surface | The service's real interface: verbs according to their meaning, the secret in a header, a request body for whatever needs one. The first surface; the second points to it. | Hauptfläche | Die eigentliche Schnittstelle des Dienstes: Verben nach ihrer Bedeutung, Geheimnis in der Kopfzeile, Anfragekörper für alles, was einen braucht. Die erste Fläche; die zweite verweist auf sie. |
| second surface, emergency exit | The deliberately restricted surface under its own prefix on which everything goes through `GET`. "Emergency exit" is meant literally: you take it when the door does not open. | zweite Fläche, Notausgang | Die bewusst eingeschränkte Fläche unter eigenem Präfix, auf der alles über `GET` geht. „Notausgang" ist wörtlich gemeint: Man nimmt ihn, wenn die Tür nicht geht. |
| GET-only caller | A tool that can fetch an address and nothing else: no other verb, no header of its own, no request body, often no selectable media type and no query part. | GET-only-Aufrufer | Ein Werkzeug, das eine Adresse abrufen kann und sonst nichts: kein anderes Verb, keine eigene Kopfzeile, kein Anfragekörper, häufig kein wählbarer Medientyp und kein Abfrageteil. |
| pass-through | A surface that only invokes existing operations and implements nothing itself. Not a facade, which describes a foreign API without touching its traffic; the pass-through lies in one's own service and forwards each call to the one operation that performs it. | Durchreiche | Eine Fläche, die ausschließlich bestehende Vorgänge aufruft und nichts selbst umsetzt. Keine Fassade, die eine fremde API beschreibt, ohne deren Datenverkehr zu berühren; die Durchreiche liegt im eigenen Dienst und leitet jeden Aufruf an den einen Vorgang weiter, der ihn ausführt. |
| path segment | A part of an address's path delimited by slashes. This surface uses only path segments. | Wegsegment | Ein durch Schrägstriche begrenzter Teil des Pfades einer Adresse. Diese Fläche benutzt nur Wegsegmente. |
| query part | The part of an address after the question mark (`?name=value&…`). Not used on this surface. | Abfrageteil | Der Teil einer Adresse hinter dem Fragezeichen (`?name=wert&…`). Auf dieser Fläche nicht benutzt. |
| secret | Any confidential credential the caller needs; here it travels as the first path segment after the prefix. | Geheimnis | Jedes vertrauliche Zugangsdatum, das der Aufrufer braucht; hier reist es als erstes Wegsegment nach dem Präfix. |
| token | The recommended access artifact: narrowly cut, one capability at one place. Every token is a secret; not every secret is a token. | Token | Das empfohlene Zugangsartefakt: eng geschnitten, eine Fähigkeit an einem Ort. Jedes Token ist ein Geheimnis; nicht jedes Geheimnis ist ein Token. |
| identifier | An address the service assigns to an object (a file, an operation, a composition, an open upload). An address, not a permission: it opens nothing without the secret it belongs to. | Kennung | Eine vom Dienst vergebene Adresse für einen Gegenstand (Datei, Vorgang, Komposition, offener Upload). Eine Adresse, keine Berechtigung: Sie öffnet nichts ohne das Geheimnis, zu dem sie gehört. |
| part | A numbered piece of a file that arrives over several fetches. | Stück | Ein nummerierter Teil einer Datei, die über mehrere Abrufe ankommt. |
| staging area | The place where parts and compositions lie before a completion moves them on; what lies there is incomplete by definition and is swept after a fixed period. | Vorraum | Der Ort, an dem Stücke und Kompositionen liegen, bevor ein Abschluss sie überführt; was dort liegt, ist per Definition unvollständig und wird nach einer Frist weggeräumt. |
| store | The permanent place the main surface knows for finished files and accepted operations. | Bestand | Der dauerhafte Ort, den die Hauptfläche für fertige Dateien und angenommene Vorgänge kennt. |
| sweeper | The process that empties the staging area after its fixed period. | Kehrer | Der Lauf, der den Vorraum nach seiner Frist leert. |
| composition | The thing assembled on the server over several fetches until one call deposits it. Not a draft: "draft" names only a state the result may have at the target system. | Komposition | Das Gebilde, das auf dem Server über mehrere Abrufe zusammengesetzt wird, bis ein Aufruf es ablegt. Kein Entwurf: „Entwurf" bezeichnet nur einen Zustand, den das Ergebnis am Zielsystem haben kann. |
| draft | Only a state the result may have at the target system; never the thing on the server. | Entwurf | Nur ein Zustand, den das Ergebnis am Zielsystem haben kann; nie das Bauteil auf dem Server. |
| deposit | The one irreversible call that takes effect and hands a composition to the main surface's operation. | ablegen | Der eine wirkende, unwiderrufliche Aufruf, der eine Komposition an den Vorgang der Hauptfläche übergibt. |
| finish | The call without consequence that assembles the parts of an upload and hands the file to the store. Named differently from deposit on purpose. | abschließen | Der folgenlose Aufruf, der die Stücke eines Uploads zusammensetzt und die Datei in den Bestand übergibt. Absichtlich anders benannt als ablegen. |
| receipt | The answer of the depositing call, kept on the composition so that a repetition gets the same answer. | Quittung | Die Antwort des ablegenden Aufrufs, an der Komposition aufbewahrt, damit eine Wiederholung dieselbe Antwort bekommt. |
| idempotency key | The value chosen by the caller in the path of the depositing call that makes the same call twice not take effect twice. | Wiederholungsschlüssel | Der vom Aufrufer gewählte Wert im Pfad des ablegenden Aufrufs, der dafür sorgt, dass derselbe Aufruf zweimal nicht zweimal wirkt. |
| base64url | The encoding free text travels in on this surface: the alphabet with `-` and `_` instead of `+` and `/`, without padding; it contains no slash and cannot fail at routing. | base64url | Die Kodierung, in der freier Text auf dieser Fläche reist: das Alphabet mit `-` und `_` statt `+` und `/`, ohne Auffüllzeichen; es enthält keinen Schrägstrich und kann am Wegfinden nicht scheitern. |
| free text | Any value that may contain a slash: a subject, a text body, the content of a file part. | freier Text | Jeder Wert, der einen Schrägstrich enthalten darf: ein Betreff, ein Textkörper, der Inhalt eines Datei-Stücks. |
| mode of interaction | The form in which a caller deals with the service: reading prose or processing structures. This surface answers as text by default. | Betriebsart | Die Form, in der ein Aufrufer mit dem Dienst verkehrt: Prosa lesen oder Strukturen verarbeiten. Diese Fläche antwortet in der Voreinstellung als Text. |
| address pattern | The address forms shown in this bundle; patterns, not a house convention. Everything is interchangeable except the shape: secret, thing, action, value. | Adressmuster | Die gezeigten Adressformen; Muster, keine Hauskonvention. Austauschbar ist alles außer der Form: Geheimnis, Gegenstand, Handlung, Wert. |
| open self-description, discovery | The part of a service retrievable without a secret that says what it can do: entry page, usage description, interface description. | offene Selbstauskunft, Discovery | Der ohne Geheimnis abrufbare Teil eines Dienstes, der sagt, was er kann: Einstieg, Benutzungsbeschreibung, Schnittstellenbeschreibung. |
| entry page | The first address of a service, which points to its descriptions; on it, one sentence points to the second surface. | Einstieg | Die erste Adresse eines Dienstes, die auf seine Beschreibungen verweist; dort verweist ein Satz auf die zweite Fläche. |
| refusal | An answer that declines a call and says why and what to do instead. | Ablehnung | Eine Antwort, die einen Aufruf zurückweist und sagt, warum und was stattdessen zu tun ist. |
| structural test | A test in the build that holds, on the code rather than on behavior, that the surface invokes operations instead of performing them. | Strukturprüfung | Eine Prüfung im Bau, die am Code statt am Verhalten festhält, dass die Fläche Vorgänge aufruft statt ausführt. |
| reader without inside knowledge | A reviewer that has only what a stranger would have: address, secret, task; no source code, no history. | Leser ohne Innensicht | Ein Prüfer, der nur hat, was ein Fremder hätte: Adresse, Geheimnis, Aufgabe; kein Quelltext, keine Vorgeschichte. |
| pass-through file | A file with tight permissions whose content flows straight into the call and appears nowhere. | Durchleitungs-Datei | Eine Datei mit engen Rechten, deren Inhalt direkt in den Aufruf fließt und nirgends erscheint. |
| ranking | The order in which a service or agent takes a secret: environment variable, then pass-through file, then context window; broken on this surface. | Rangfolge | Die Reihenfolge, in der ein Dienst oder Agent ein Geheimnis bezieht: Umgebungsvariable, dann Durchleitungs-Datei, dann Kontextfenster; auf dieser Fläche durchbrochen. |
| context window | What an agent holds in its working memory during a session; a secret seen there is persisted at once and never repeated. | Kontextfenster | Was ein Agent während einer Sitzung im Arbeitsgedächtnis hält; ein dort gesehenes Geheimnis wird sofort abgelegt und nie wiederholt. |
| breach | A rule broken knowingly at one named place, with its price stated; not a second rule. | Durchbrechung | Eine Regel, wissentlich an einer benannten Stelle gebrochen, mit ausgesprochenem Preis; keine zweite Regel. |
| prefetching | A tool or station fetching an address in advance, without being asked, because `GET` promises no effect. | Vorabladen | Ein Werkzeug oder eine Station ruft eine Adresse vorab ab, ohne Auftrag, weil `GET` Folgenlosigkeit verspricht. |
| rule | An entry with one answer; giving it up means no longer using the concept. | Festlegung | Ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| load-bearing | A rule the rest of the concept depends on. | tragend | Eine Festlegung, von der der Rest des Konzepts abhängt. |
| builder | Whoever builds the service and its surfaces. | Erbauer | Wer den Dienst und seine Flächen baut. |
| operator | Whoever runs the service and issues its secrets. | Betreiber | Wer den Dienst betreibt und seine Geheimnisse ausstellt. |
| consumer | Whoever calls the service, here usually an agent with a GET-only tool. | Konsument | Wer den Dienst aufruft, hier meist ein Agent mit einem GET-only-Werkzeug. |
| user | The person an agent works for; gives the consent before the depositing call. | Anwender | Die Person, für die ein Agent arbeitet; gibt die Zustimmung vor dem ablegenden Aufruf. |
