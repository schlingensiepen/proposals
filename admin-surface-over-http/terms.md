# Terms

The concrete forms shown in this bundle are patterns, not a house convention: the prefix `/admin/v1`, the variable `<SERVICE>_ADMIN_TOKEN`, the value `new`, the minimum length of 32 characters, the port number. Everything is interchangeable except the shape: own port, own name, one secret in a fixed ranking, once in the log. Account, queue, file pool, deliverer, third-system password and the named actions on them are the items of the reference service and are named here as examples; your service has its own items and actions.

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Administration surface | the second surface described here: an application reachable over HTTP through which the service is configured, inspected and provided with accesses. Not provided for in the base cut; here the named exception. | Verwaltungsfläche | die hier beschriebene zweite Fläche: eine über HTTP erreichbare Anwendung, über die der Dienst konfiguriert, inspiziert und mit Zugängen versehen wird. Im Grundlagen-Zuschnitt nicht vorgesehen; hier die benannte Ausnahme. |
| Base cut | the cut of the extended concept: one service, one function, one artifact with modes, administration as a command, no administration surface, no administrative rights. | Grundlagen-Zuschnitt | der Zuschnitt des erweiterten Konzepts: ein Dienst, eine Funktion, ein Artefakt mit Modi, Verwaltung als Kommando, keine Verwaltungsfläche, keine Verwaltungsrechte. |
| Command | the one-off invocation of the same artifact for the same administrative actions, started locally, without a login of its own; the normal way where there is a shell. | Kommando | der Einmal-Aufruf desselben Artefakts für dieselben Verwaltungshandlungen, lokal gestartet, ohne eigene Anmeldung; der Normalweg, wo eine Shell ist. |
| User-facing surface | the network surface of the service's actual function, with its accesses. Untouched by this extension: no administration path, no debug path. | Nutzfläche | die Netzfläche der eigentlichen Funktion des Dienstes, mit ihren Zugängen. Von dieser Erweiterung unberührt: kein Verwaltungspfad, kein Debug-Pfad. |
| Operation | an administrative action as a callable function that knows neither HTTP nor process exit: it takes arguments, acts on the store or the target system, and returns a result or an error kind of its own. Every operation exists exactly once. | Vorgang | eine Verwaltungshandlung als aufrufbare Funktion, die weder HTTP noch Prozessende kennt: Sie nimmt Argumente, wirkt auf den Bestand oder das Zielsystem und gibt ein Ergebnis oder eine eigene Fehlerart zurück. Jeder Vorgang existiert genau einmal. |
| Pass-through | a surface that only calls existing operations and implements nothing itself: it reads arguments, calls the operation, translates the result into its vocabulary. Command line and administration surface are the two pass-throughs here. The author's implementation calls the same thing a "facade"; this bundle does not, because in this series that word is used for something else (a retrofitted description service for someone else's interface), and one word should not name two things. | Durchreiche | eine Fläche, die ausschließlich bestehende Vorgänge aufruft und nichts selbst umsetzt: Sie liest Argumente, ruft den Vorgang, übersetzt das Ergebnis in ihr Vokabular. Kommandozeile und Verwaltungsfläche sind hier die zwei Durchreichen. Die Umsetzung des Autors nennt dasselbe „Fassade"; dieses Bundle nicht, weil das Wort in dieser Reihe für etwas anderes vergeben ist (einen nachgerüsteten Beschreibungsdienst einer fremden Schnittstelle) und ein Wort nicht zwei Dinge bezeichnen soll. |
| Translation function | the one function per surface that maps the error kinds of the operations to status codes or exit codes; the only place where HTTP or exit-code knowledge lives. | Übersetzungsfunktion | die eine Funktion je Fläche, die die Fehlerarten der Vorgänge auf Statuscodes beziehungsweise Exit-Codes abbildet; der einzige Ort, an dem HTTP- oder Exit-Code-Wissen wohnt. |
| Structural test | a test in the build that parses the source of the pass-throughs (imports, names used, file system access, calls) and fails where an operation is performed there instead of called. | Strukturprüfung | eine Prüfung im Bau, die den Quelltext der Durchreichen zerlegt (Importe, verwendete Namen, Dateisystemzugriffe, Aufrufe) und fehlschlägt, wo dort ein Vorgang ausgeführt statt aufgerufen wird. |
| Behavioral test | a test that uses the service and checks its result; it cannot tell two correct copies apart. | Verhaltensprobe | eine Prüfung, die den Dienst benutzt und sein Ergebnis prüft; sie kann zwei richtige Kopien nicht auseinanderhalten. |
| Red check | running an assertion once with its protection removed and seeing it fail before trusting it. | Rot-Probe | eine Zusicherung einmal mit entfernter Absicherung laufen lassen und sie rot sehen, bevor man ihr traut. |
| Administration secret | the one secret with which the administration surface authenticates. It is not an access to the function; it can issue accesses. | Verwaltungsgeheimnis | das eine Geheimnis, mit dem die Verwaltungsfläche authentifiziert. Es ist kein Zugang zur Funktion; es kann Zugänge ausstellen. |
| Access | the artifact with which a caller uses the function (as a rule a narrowly cut token), issued by an operation both pass-throughs call. | Zugang | das Artefakt, mit dem ein Aufrufer die Funktion benutzt (in der Regel ein eng geschnittenes Token), ausgestellt von einem Vorgang, den beide Durchreichen aufrufen. |
| Root, leaf | the position of a secret in the rights hierarchy: a leaf carries one capability and nothing else; the root can issue and withdraw leaves. The base cut knows only leaves. | Wurzel, Blatt | die Stellung eines Geheimnisses in der Rechtehierarchie: Ein Blatt trägt eine Fähigkeit und sonst nichts; die Wurzel kann Blätter ausstellen und entziehen. Der Grundlagen-Zuschnitt kennt nur Blätter. |
| Start secret | a secret that has to come from outside before the service can do anything; its origin is governed by the imported concept `where-a-secret-comes-from`. | Start-Geheimnis | ein Geheimnis, das von außen kommen muss, bevor der Dienst etwas tun kann; seine Herkunft regelt das importierte Konzept `where-a-secret-comes-from`. |
| Ranking | the order of the sources from which the administration secret is taken: environment variable before stored file before generation. | Rangfolge | die Reihenfolge der Quellen, aus denen das Verwaltungsgeheimnis genommen wird: Umgebungsvariable vor gespeicherter Datei vor Erzeugung. |
| Pass-through file | the second rank of the ranking: a file with tight permissions beside the store whose content flows straight into the service and appears nowhere, whatever placed it there; here the service writes it itself at generation, and `new` with a restart replaces it (the term is the imported concept's). | Durchleitungsdatei | der zweite Rang der Rangfolge: eine Datei mit engen Rechten neben dem Bestand, deren Inhalt direkt in den Dienst fließt und nirgends erscheint, gleich wer sie dort abgelegt hat; hier schreibt der Dienst sie bei der Erzeugung selbst, und `new` mit Neustart ersetzt sie (der Begriff ist der des importierten Konzepts). |
| Lower rank | a source that is hidden by a higher one and becomes effective again as soon as the higher one is missing. | Unterer Rang | eine Quelle, die von einer höheren verdeckt wird und wieder wirksam wird, sobald die höhere fehlt. |
| Latent access | a secret in a lower rank that nobody knows any more and that still applies as soon as the upper rank disappears. | Latenter Zugang | ein Geheimnis in einem unteren Rang, das niemand mehr kennt und das trotzdem gilt, sobald der obere Rang entfällt. |
| Once-only channel | the one place where a generated secret is shown, exactly once, at creation; for a service without a shell its log. | Einmal-Kanal | die eine Stelle, an der ein erzeugtes Geheimnis gezeigt wird, genau einmal, bei Erzeugung; für einen Dienst ohne Shell sein Protokoll. |
| As-shipped state | the artifact's behavior without any setting by the operator. The administration surface is off in this state; whether it is switched on is decided with the user, and the deployment then sets the address as environment. | Auslieferungszustand | das Verhalten des Artefakts ohne jede Angabe des Betreibers. Die Verwaltungsfläche ist in diesem Zustand aus; ob sie eingeschaltet wird, wird mit dem Anwender entschieden, und das Ausrollen setzt dann die Adresse als Umgebung. |
| Host system | the machine or platform on which the service runs. | Trägersystem | die Maschine oder Plattform, auf der der Dienst läuft. |
| Shell | the possibility of running a command on the host system. This extension applies to operators who have neither a shell nor a one-off invocation. | Shell | die Möglichkeit, auf dem Trägersystem ein Kommando auszuführen. Diese Erweiterung gilt für Betreiber, die weder Shell noch Einmal-Aufruf haben. |
| One-off invocation | running a command against the running container. | Einmal-Aufruf | ein Kommando gegen den laufenden Behälter ausführen. |
| Log | the service's output that the operator can read through his platform; when running without a shell, his only back channel out of the container. | Protokoll | die Ausgabe des Dienstes, die der Betreiber über seine Plattform lesen kann; beim Betrieb ohne Shell sein einziger Rückkanal aus dem Behälter. |
| Pushing, pulling | the two directions of delivery: a script with access to the host system places files there (pushing), or the host fetches an image from a registry itself (pulling). | Schieben, Ziehen | die zwei Richtungen der Auslieferung: Ein Skript mit Zugang zum Trägersystem legt dort Dateien ab (Schieben), oder der Träger holt sich ein Abbild selbst aus einer Registry (Ziehen). |
| Store | the variants and their accesses that the setup operation creates; state, not configuration. | Bestand | die Ausprägungen und ihre Zugänge, die der Einrichtungsvorgang anlegt; Zustand, nicht Konfiguration. |
| Variant | a concrete, preconfigured form of the function (in the reference service: an account with target system and folder) that an access embodies. | Ausprägung | eine konkrete, vorkonfigurierte Form der Funktion (im Referenzdienst: ein Konto mit Zielsystem und Ordner), die ein Zugang verkörpert. |
| Entry page | the page at the base URL of the administration surface, readable without a secret, that says what the port administers, that it is not the user-facing surface, what one needs and what the port cannot do. | Einstieg | die Seite an der Basis-URL der Verwaltungsfläche, ohne Geheimnis lesbar, die sagt, was der Port verwaltet, dass er nicht die Nutzfläche ist, was man braucht und was der Port nicht kann. |
| Readiness point | an endpoint that answers without a secret and says only "running". | Bereitschaftspunkt | ein Endpunkt, der ohne Geheimnis antwortet und nur „läuft" sagt. |
| Anchor package | a package an agent is told to store so that it can later trigger the service on its own; there is none for the administration surface. | Anker-Paket | ein Paket, das ein Agent auf „leg das ab" hin speichert, um den Dienst später von selbst auszulösen; für die Verwaltungsfläche gibt es keines. |
| Description cascade | in the reference: the chain of entry page, guide, machine-readable contract, browser view and readiness point through which a surface describes itself. | Kaskade | in der Referenz: die Kette aus Einstieg, Anleitung, maschinenlesbarem Vertrag, Browser-Ansicht und Bereitschaftspunkt, mit der eine Fläche sich selbst beschreibt. |
| Gate | in the reference: a check in the build that holds a surface's description to its rules (description and example per field, closed status catalog, reachability of every declared error). | Gate | in der Referenz: eine Prüfung im Bau, die die Beschreibung einer Fläche an ihren Regeln hält (Beschreibung und Beispiel je Feld, geschlossener Statuskatalog, Erreichbarkeit jedes deklarierten Fehlers). |
| File pool, deliverer | in the reference: the area of uploaded files, and the worker strand that delivers queued jobs to the target system. | Pool, Zusteller | in der Referenz: der Bereich hochgeladener Dateien, und der Arbeiter-Strang, der Aufträge aus der Warteschlange ans Zielsystem zustellt. |
| Builder | the person or agent who builds the administration surface into the service. | Erbauer | wer die Verwaltungsfläche in den Dienst einbaut, Mensch oder Agent. |
| Operator | the person who runs the service; where this extension applies, without a shell and without a one-off invocation. | Betreiber | wer den Dienst betreibt; wo diese Erweiterung gilt, ohne Shell und ohne Einmalaufruf. |
| Rule | an entry with one answer; giving it up means no longer using the concept. | Festlegung | ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| Choice | an entry where the concept does not decide but names options with consequences; the adopter decides and records. | Wahlpunkt | eine Stelle, an der das Konzept nicht entscheidet, sondern Optionen mit Folgen nennt; der Übernehmende entscheidet und hält fest. |
