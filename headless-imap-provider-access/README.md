# headless-imap-provider-access

**These (de):** Ein Server ohne Browser kommt bei fast allen gängigen Providern mit einem App-Passwort dauerhaft per IMAP an das Postfach; die Ausnahmen sind Microsoft (OAuth2 zwingend, browserlose Flows vorhanden) und Google Workspace (Service Account).

**Thesis (en):** A browserless server can reach almost every major provider's mailbox permanently over IMAP with an app password; the exceptions are Microsoft (OAuth2 mandatory, browserless flows exist) and Google Workspace (service account).
