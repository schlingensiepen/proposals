# microsoft-imap-app-only

**These (de):** Basic Auth ist bei Microsoft vollständig abgeschaltet und App-Passwörter sind für Mail funktionslos — es bleibt OAuth2 mit SASL XOAUTH2: Client-Credentials-Flow für Microsoft 365 (unbegrenzt unbeaufsichtigt), Device-Code-Flow mit Token-Cache für Privatkonten (90-Tage-Fenster).

**Thesis (en):** Microsoft has fully switched off basic auth and app passwords are dead for mail — what remains is OAuth2 with SASL XOAUTH2: the client-credentials flow for Microsoft 365 (unattended without limit) and the device-code flow with a persisted token cache for personal accounts (90-day window).
