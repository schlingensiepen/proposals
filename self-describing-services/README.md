# self-describing-services

**These (de):** Ein Dienst, der sich selbst beschreibt, macht Installation überflüssig — der Agent merkt sich nur die klassische Tool-Beschreibung („wenn du das willst, schau unter dieser URL") und ein Token; alles Weitere liefert der Dienst zur Laufzeit selbst, und weil es keine zweite Quelle gibt, veraltet nichts.

**Thesis (en):** A service that describes itself makes installation unnecessary — the agent remembers only the classic tool description ("if you want this, look at this URL") and a token; everything else the service delivers itself at runtime, and because there is no second source, nothing goes stale.
