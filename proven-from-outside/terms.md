# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| inside knowledge | Knowledge only whoever builds or runs the service has: requirement identifiers, decision numbers, file names, names of internal modules, project jargon. In a delivered document the reader cannot resolve it. | Innensicht | Wissen, das nur hat, wer den Dienst baut oder betreibt: Anforderungskennungen, Entscheidungsnummern, Dateinamen, Namen interner Module, Projekt-Jargon. In einem ausgelieferten Dokument ist sie für den Leser unauflösbar. |
| check (gate) | An automatic check in the build that makes the build fail when a rule is violated; the form in which a concept keeps its intentions. | Prüfregel (Gate) | Eine automatische Prüfung im Bau, die den Bau scheitern lässt, wenn eine Festlegung verletzt ist; die Form, in der ein Konzept Vorsätze hält. |
| red probe | The one-time run of a new check with its safeguard removed, in which it has to fail; the proof that it tests anything at all. | Rot-Probe | Der einmalige Lauf einer neuen Prüfregel mit entfernter Absicherung, bei dem sie scheitern muss; der Nachweis, dass sie überhaupt etwas prüft. |
| safeguard | What a check is meant to protect: the code, the rule or the passage whose absence it has to report. | Absicherung | Das, was eine Prüfregel schützen soll: der Code, die Regel oder die Stelle, deren Fehlen sie melden muss. |
| outside test | The acceptance of a document meant to work without inside knowledge by an agent that has nothing but the URL, a secret and a task in the user's language: no source code, no specification, no conversation with the builder. | Fremdprüfung | Die Abnahme eines Dokuments, das ohne Innensicht tragen soll, durch einen Agenten, der nichts hat als die URL, ein Geheimnis und eine Aufgabe in der Sprache des Anwenders: keinen Quelltext, keine Spezifikation, kein Gespräch mit dem Erbauer. |
| acceptance | The finding that a document is enough; under F2 only after a passed outside test. | Abnahme | Die Feststellung, dass ein Dokument genügt; nach F2 erst nach bestandener Fremdprüfung. |
| round | A pass of work in which the document or the interface changes; the outside test comes at its end. | Runde | Ein Arbeitsgang, in dem sich Dokument oder Schnittstelle ändern; an seinem Ende steht die Fremdprüfung. |
| finding | What a check or an outside test reports; treated as a bug report. | Befund | Was eine Prüfung oder Fremdprüfung meldet; wird wie eine Fehlermeldung behandelt. |
| surface | The interface a caller reaches and a document describes. | Fläche | Die Schnittstelle, die ein Aufrufer erreicht und die ein Dokument beschreibt. |
| narrowly scoped secret | A secret that carries exactly one capability. | eng geschnittenes Geheimnis | Ein Geheimnis, das genau eine Fähigkeit trägt. |
| builder | Whoever writes the check, or builds the document and what it describes. | Erbauer | Wer die Prüfregel schreibt oder das Dokument und das, was es beschreibt, baut. |
| user | The person the work is done for; the task of the outside test is phrased in their language. | Anwender | Die Person, für die gearbeitet wird; in ihrer Sprache ist die Aufgabe der Fremdprüfung gestellt. |
| rule | An entry with one answer; giving it up means no longer using the concept. | Festlegung | Ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| independent | A rule that holds even if the other rules of the concept are dropped. | unabhängig | Eine Festlegung, die auch gilt, wenn die übrigen Festlegungen des Konzepts entfallen. |
