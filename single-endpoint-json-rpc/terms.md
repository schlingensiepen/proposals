# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Endpoint | an address requests go to. Here: exactly one for all application logic. | Endpunkt | eine Adresse, an die Anfragen gehen. Hier: genau eine für die gesamte Fachlogik. |
| Envelope | the fixed wrapper every request and response sits in; here the JSON-RPC 2.0 object with `jsonrpc`, `method`, `params`, `id` and `result`/`error` respectively. | Umschlag | die feste Hülle, in der jede Anfrage und jede Antwort steckt; hier das JSON-RPC-2.0-Objekt mit `jsonrpc`, `method`, `params`, `id` beziehungsweise `result`/`error`. |
| JSON-RPC 2.0 | a very terse standard for remote calls over any transport, finalized in 2010. It defines exactly the envelope and a handful of protocol errors; nothing else. | JSON-RPC 2.0 | ein 2010 verabschiedeter, sehr knapper Standard für entfernte Aufrufe über einen beliebigen Transportweg. Er definiert genau den Umschlag und eine Handvoll Protokollfehler; sonst nichts. |
| Default document | the file a web server serves when an address points at a directory (`index.php`, `default.aspx`). Every server does this in its core, without an add-on module. | Standarddokument | die Datei, die ein Webserver ausliefert, wenn eine Adresse auf ein Verzeichnis zeigt (`index.php`, `default.aspx`). Jeder Server kann das im Kern, ohne Zusatzmodul. |
| URL rewriting | a server module rewriting addresses onto other files. Not reliably present on cheap hosting. | URL-Rewriting | das Umschreiben von Adressen auf andere Dateien durch ein Servermodul. Auf günstigem Hosting nicht verlässlich vorhanden. |
| Protocol error | an error in the form of a call (unreadable JSON, invalid envelope, unknown method, `params` not an object), reported with the codes the standard reserves (F6). | Protokollfehler | ein Fehler in der Form eines Aufrufs (unlesbares JSON, ungültiger Umschlag, unbekannte Methode, `params` kein Objekt), gemeldet mit den vom Standard reservierten Codes (F6). |
| Application error | an error in the content of a call, reported with an HTTP-style code, a machine-readable type and plain text (F5, F6). | Fachfehler | ein Fehler im Inhalt eines Aufrufs, gemeldet mit einem HTTP-artigen Code, einem maschinenlesbaren Typ und Klartext (F5, F6). |
| Credential | a piece of evidence with which a caller shows who or what it is: session cookie, API key, administrative key. | Nachweis | eine Angabe, mit der ein Aufrufer belegt, wer oder was er ist: Sitzungs-Cookie, API-Schlüssel, Verwaltungsschlüssel. |
| Session credential | the cookie that shows "this person on this device"; set by the server via `Set-Cookie`, long-lived, individually revocable (F7). | Sitzungsnachweis | das Cookie, das „dieser Mensch auf diesem Gerät" belegt; vom Server per `Set-Cookie` gesetzt, langlebig, einzeln entziehbar (F7). |
| Machine key | a credential in a header of its own that shows "this process may do this job"; created at setup and shown in clear exactly once (F7). | Maschinenschlüssel | ein Nachweis in einem eigenen Header, der „dieser Prozess darf diese Aufgabe" belegt; bei der Einrichtung erzeugt und genau einmal im Klartext ausgegeben (F7). |
| Administrative key | a credential in a header of its own that shows "the operator, during setup"; created when the system is set up (F7). | Verwaltungsschlüssel | ein Nachweis in einem eigenen Header, der „der Betreiber, im Einrichtungsvorgang" belegt; beim Aufsetzen erzeugt (F7). |
| Redemption secret | a secret presented once and exchanged for a lasting credential; typically the token from an invitation link. | Einlöse-Nachweis | ein einmalig vorzulegendes Geheimnis, das gegen einen dauerhaften Nachweis getauscht wird; typischerweise der Token aus einem Einladungslink. |
| Fragment | the part of an address after the `#`. The browser does not send it to the server, so it appears in no access log and no `Referer`; only code in the browser sees it. | Fragment | der Teil einer Adresse hinter dem `#`. Er wird vom Browser nicht an den Server geschickt und steht deshalb in keinem Zugriffslog und in keinem `Referer`; nur Code im Browser sieht ihn. |
| Bearer credential | a credential that lets whoever holds it act, without any further check; every token is one, and so is an unguessable address (F8). | Inhaber-Nachweis | ein Nachweis, mit dem handeln darf, wer ihn hat, ohne weitere Prüfung; jeder Token ist einer, ebenso eine unerratbare Adresse (F8). |
| Handle | an unpredictable string naming an uploaded file before anyone knows what it belongs to. | Kennung | eine unvorhersehbare Zeichenkette, die eine hochgeladene Datei benennt, bevor irgendjemand weiß, wozu sie gehört. |
| Barrier | one of the three protections of a directly served upload area, graded by obligation: content-type check, default documents against listing, disabled script execution (F9). | Riegel | einer der drei Schutzmaßnahmen eines direkt ausgelieferten Upload-Bereichs, nach Verbindlichkeit gestuft: Prüfung des Inhaltstyps, Standarddokumente gegen das Listing, abgeschaltete Skriptausführung (F9). |
| Provision | a file compiled on commission that contains much or all of the data: a backup, an export. To be distinguished from an attachment. | Bereitstellung | eine auf Auftrag zusammengestellte Datei, die vieles oder alles enthält: eine Datensicherung, ein Export. Abzugrenzen vom Anhang. |
| Attachment | a file that is part of the domain data and comes into being with it; its address exposes one file only. | Anhang | eine Datei, die Teil der Fachdaten ist und mit ihnen entsteht; ihre Adresse offenbart nur eine Datei. |
| Job handle | the identifier a commissioning call returns when a provision is compiled concurrently; the download path follows only after completion (F12). | Auftragskennung | die Kennung, die ein beauftragender Aufruf zurückgibt, wenn eine Bereitstellung nebenläufig erstellt wird; der Download-Pfad folgt erst nach Abschluss (F12). |
| Lazy enforcement | enforcing an expiry without a scheduled process: every call to the provisioning methods clears expired provisions along the way (F12). | träge Vollstreckung | das Durchsetzen einer Frist ohne zeitgesteuerten Prozess: Jeder Aufruf der Bereitstellungsmethoden räumt abgelaufene Bereitstellungen mit weg (F12). |
| Origin | the combination of scheme, host and port. Two addresses with the same origin count as the same source to the browser; that decides about cookies and about whether a call needs a preflight. | Origin | die Kombination aus Schema, Host und Port. Zwei Adressen mit gleicher Origin gelten dem Browser als dieselbe Herkunft; das entscheidet über Cookies und über die Frage, ob ein Aufruf einen Preflight braucht. |
| rule | An entry with one answer; giving it up means no longer using the concept. | Festlegung | Ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
