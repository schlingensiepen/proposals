# Terms

| English term | Explanation | Deutscher Begriff | Erläuterung |
|---|---|---|---|
| Self-contained | understandable and followable on its own, without access to documents outside the repository. | Selbsttragend | verständlich und befolgbar aus sich heraus, ohne Zugriff auf Dokumente außerhalb des Repositoriums. |
| Entry point | the one file that an arriving person reads first and that branches them to the instruction that fits their task. | Einstieg | die eine Datei, die ein Ankommender zuerst liest und die ihn auf die zu seiner Aufgabe passende Anweisung verzweigt. |
| Task definition | an instruction for exactly one recurring activity on this repository, followable on its own. | Aufgabendefinition | eine Anweisung für genau eine wiederkehrende Tätigkeit an diesem Repository, aus sich heraus befolgbar. |
| Decision | a determination that has been made, with its reasons and the alternatives considered; often kept in a log of its own. | Entscheidung | eine getroffene Festlegung mit ihrer Begründung und den erwogenen Alternativen; oft in einem eigenen Protokoll geführt. |
| Decision log | the chronological record of decisions with date and course; history, not the place where work happens. | Entscheidungsprotokoll | die chronologische Aufzeichnung der Entscheidungen mit Datum und Verlauf; Historie, nicht der Ort, an dem gearbeitet wird. |
| Inlining | taking the statement and reasons of a decision into the document that needs them, instead of a link. | Inlining | das Übernehmen von Aussage und Begründung einer Entscheidung in das Dokument, das sie braucht, statt eines Verweises. |
| Provenance note | a reference to the source of a statement that serves only maintenance and is not needed for understanding. | Herkunftsvermerk | ein Verweis auf die Quelle einer Aussage, der ausschließlich der Wartung dient und für das Verständnis nicht gebraucht wird. |
| Prerequisite for understanding | a reference without whose target one cannot follow the text; exactly what must not occur in a self-contained repository. | Verständnisvoraussetzung | ein Verweis, ohne dessen Ziel man den Text nicht befolgen kann; genau das, was in einem selbsttragenden Repository nicht vorkommen darf. |
| Link rot | the state in which a link points into nothing and the knowledge behind it is lost, although the referring document still looks complete. | Verweis-Verrottung | der Zustand, in dem ein Link ins Leere zeigt und das Wissen dahinter verloren ist, obwohl das verweisende Dokument noch vollständig wirkt. |
| Check rule (dead-link test) | the question whether the repository is still understood and followed when every external link is dead (F1). | Prüfregel | die Frage, ob man das Repository noch versteht und befolgt, wenn jeder externe Link tot ist (F1). |
| Pairing | two places in the repository that say the same thing in different forms and must be changed together (F6). | Paarung | zwei Stellen im Repository, die dasselbe in verschiedener Form sagen und gemeinsam geändert werden müssen (F6). |
| Generated file | a file produced from other files; it carries a visible note and names its leading source (F7). | Erzeugte Datei | eine aus anderen Dateien hergestellte Datei; sie trägt einen sichtbaren Hinweis und benennt ihre führende Quelle (F7). |
| Writer | whoever writes documents in the repository and does not notice what they silently presuppose. | Verfasser | wer im Repository Dokumente schreibt und dabei nicht merkt, was er stillschweigend voraussetzt. |
| Successor | whoever takes over the repository later and finds decisions whose reasons nobody knows any more. | Übernehmender | wer das Repository später übernimmt und Entscheidungen vorfindet, deren Begründung niemand mehr kennt. |
| Maintainer | whoever keeps the repository current and carries changes to all affected places. | Pflegender | wer das Repository aktuell hält und Änderungen an alle betroffenen Stellen trägt. |
| rule | An entry with one answer; giving it up means no longer using the concept. | Festlegung | Ein Eintrag mit einer Antwort; wer sie aufgibt, benutzt das Konzept nicht. |
| choice | An entry where the concept does not decide but names options with consequences; the adopter decides and records. | Wahlpunkt | Eine Stelle, an der das Konzept nicht entscheidet, sondern Optionen mit Folgen nennt; der Übernehmende entscheidet und hält fest. |
